# Brainstorm Techniques — Collaborative

Detail file. Load only when a technique from this category is selected in PHASE 3.

### 8. "Yes, And..." Building

**When to use:** To build on ideas iteratively without blocking or criticism.

**Approach:**

- Start with base idea
- Add "Yes, and what if we also..." variations
- Build on each addition without rejecting
- Iterate across generations: create variations of variations, alternate between different directions, cross-pollinate branches
- Allow ideas to evolve through additions
- Find unexpected combinations

**Output structure:**

- Base idea
- Chain of "yes, and" additions (generation 1, generation 2+ where valuable)
- Most interesting evolved versions and hybrid combinations
- Unexpected emergent features

### 9. Random Stimulation

**When to use:** To break patterns and discover unexpected connections.

**Approach:**

- Pick random words/concepts/images — or deliberately choose unrelated concepts to pair with the idea
- Force connections between the unrelated element and your idea
- Ask: How could [element] inspire a feature? What if we combined [X] with [Y]?
- Look for metaphorical connections and structural similarities
- Embrace absurdity to find novelty

**Output structure:**

- Elements used (random or deliberately paired)
- Forced connections made
- Valuable insights and surprising synergies from unexpected links
- Novel features, hybrid concepts, or approaches discovered
- Refined ideas removing absurdity but keeping innovation

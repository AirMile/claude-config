# Stack Baseline Research

Shared procedure for generating `.claude/research/stack-baseline.md`. Used by `mode-greenfield.md` Phase 7 and `mode-mature.md` PHASE 5.85.

---

## Goal

Generate `.claude/research/stack-baseline.md` — reusable framework conventions that prevent duplicate Context7 queries in other skills. A teammate (or greenfield setup) then does not need to look up the same tech docs again.

## Trigger condition

Only execute when:

- `stack.framework` is filled in (at least one major technology known)
- `.claude/research/stack-baseline.md` does **not** exist yet (idempotent — restart-safe)

## Execution

**Run as general-purpose agent** (`subagent_type="general-purpose"`) for context isolation — Context7 queries for multiple stack technologies produce substantial output that does not belong in the main session. The agent needs Write access; Explore is read-only and won't work.

1. Create the directory first: `mkdir -p .claude/research`
2. Determine the major technologies from `stack.framework`, `stack.language`, `stack.styling`, `stack.db`, `stack.auth` (skip empty fields)
3. For each technology, query Context7 (`resolve-library-id` → `query-docs`)
4. Distill per technology:
   - **Conventions** (5-10): naming, structure, configuration patterns
   - **Patterns** (5-10): common solutions, idioms
   - **Testing** (3-5): test setup, mocking conventions, assertions
   - **Pitfalls** (3-5): known pitfalls, version-specific bugs, migration issues
5. Write the result directly to `.claude/research/stack-baseline.md`
6. Add a Context7 library IDs table at the bottom for follow-up queries

**Game projects (Godot):** also generate `.claude/research/architecture-baseline.md` with scene tree patterns, node types, signals, state machines.

## Output format

```markdown
# Stack Baseline

Generated by /core-setup on {date}. Reusable across all skills — do not edit manually.

## {Framework/Library name}

### Conventions

- ...

### Patterns

- ...

### Testing

- ...

### Pitfalls

- ...

---

## Context7 Library IDs

| Technology | Library ID |
| ---------- | ---------- |
| {name}     | {id}       |
```
